# sponge-ops-os

매번 손으로 하던 운영 일을 **하나씩** 덜어 주는 Claude Code 스킬입니다. 한 번에 운영 전체를 자동화하지 않고 **v1 → v2 → v3** 로 끊어서 갑니다.

1차 전환 흐름(신청 → 가두리망 → 메시지)만이 아니라 세금계산서·직원·알바·정산·고객 메시지·예약·주문·문의·리뷰·콘텐츠 발행·숫자 보고까지 — AI 와 인터뷰하며 **운영 지도**를 그리고, 점수로 v1 하나를 골라 바로 만듭니다.

| 버전 | 무엇 |
|---|---|
| v1 | 손으로 하던 일 하나 · 반자동(내가 확인하고 버튼 하나) · 하루 안에 |
| v2 | 며칠 써 본 기록으로 **깊게**(같은 일을 더 자동으로) 또는 **넓게**(다음 일) |
| v3 | 운영 중인 두세 개 일을 한 화면에 = 내 운영 OS |

## 설치
```bash
git clone https://github.com/selfishclub/sponge-ops-os ~/.claude/skills/sponge-ops-os
```
Claude Code 를 다시 열면 `/sponge-ops-os` 로 부를 수 있습니다. "운영 OS 만들어 줘", "매번 손으로 하는 일 줄이고 싶어"라고만 해도 뜹니다.

## 준비물
| 무엇 | 왜 |
|---|---|
| Claude Code (Desktop 앱 권장) | 인터뷰·구현. 예약 작업 형태는 Desktop 에서 돕니다 |
| 내 프로젝트 폴더 (있으면) | 1차 전환 랜딩·어드민 저장소. 없어도 됩니다 — 코드 없이 시트·예약 작업으로 끝나는 일이 많아요 |
| 구글 계정 (선택) | 시트 + Apps Script 형태일 때 |
| 브라우저 에이전트 (선택) | 공식 연결이 없는 화면을 다룰 때. 아래 표에서 상황에 맞게 추천합니다 |

## 모드
| 모드 | 하는 일 | 언제 |
|---|---|---|
| ① 처음 | 인터뷰 → 운영 지도 → v1 고르기 → 기획안(v1·v2·v3) → v1 구현 → 사용 기록 시작 | 처음 |
| ② 다시 | 사용 기록으로 줄어든 시간 계산 → v1 고치기 / 깊게 / 넓게 / v3 연결 → 기획안 → 구현 | v1 을 5번 넘게 썼거나 일주일 지났을 때 |
| ③ 지도만 | 인터뷰 → 운영 지도 → v1 기획안까지. 구현 없음 | 시간이 없거나 준비·심사를 기다려야 할 때 |

`<프로젝트>/docs/ops-os/` 에 운영 지도·기획안·사용 기록이 쌓이고, 스킬이 그걸 읽어 어느 모드인지 스스로 정합니다.

## 가벼운 형태부터
| 칸 | 형태 | 예 |
|---|---|---|
| 1 | Claude 예약 작업 | 매주 월요일 지난주 신청·유입 요약을 나에게 |
| 2 | 구글 시트 + Apps Script | 세금계산서 발행 목록 + 기한 5일·9일 알림 메일 |
| 3 | 브라우저 에이전트 | 홈택스 입력칸은 AI 가 채우고, 인증·발급 버튼은 내가 |
| 4 | 기존 어드민에 화면 | 「오늘 보낼 사람」 목록 + 문구 + 복사 버튼 |
| 5 | 새 작은 앱 | 알바가 쓰는 스케줄 페이지 (데이터를 랜딩과 분리해야 할 때) |

기존 프로젝트 저장소에 연결하는 게 기본이고, 정말 다른 일일 때만 새 저장소를 추천합니다.

## 브라우저 에이전트 — 이럴 때 이것
| 상황 | 도구 |
|---|---|
| 로그인된 대시보드에서 한 번, 내가 지켜볼 때 | Claude in Chrome |
| AI 가 입력칸을 채우고 인증·최종 버튼은 내가 | ego lite |
| 매주 같은 화면을 읽어 오기 | Playwright (탐색한 뒤 스크립트로 굳힘) |
| 반복 루틴인데 스크립트를 관리할 사람이 없음 | Aside |

인스타그램·카카오·네이버는 약관상 자동 조작이 막혀 있어서, 공식 연결이 없으면 **초안 + 복사 버튼**까지만 합니다. 은행·결제 화면에는 쓰지 않습니다.

## 예시 대화
1. "운영 OS 만들어 줘." → 흐름 읽기 → 인터뷰 → 운영 지도 → "1위 후속 메시지 · 2위 주간 숫자 보고 · 3위 세금계산서 기한" → v1 기획안 → 어드민에 「오늘 보낼 사람」 화면.
2. "세금계산서 매달 10일 전에 몰아서 하다가 가산세 냈어." → 발행 목록 시트 + 사업자 상태 조회 + 5일·9일 알림 → 발급은 홈택스에서 내가.
3. "운영 OS 다시 — v1 을 8번 썼어." → 기록 집계 → "주 60분 → 주 15분 · 문구를 거의 안 고침 → v2 깊게: 알림톡 정보성 자동 발송 (채널 심사 3~7일)".

## AI가 절대 하지 않는 것
키·비밀번호·인증서 비밀번호 입력, 홈택스·은행 로그인, 송금·결제, 신고·발급 버튼 대신 누르기, 광고 메시지 자동 발송, 인스타·카카오·네이버 자동 조작, 주민번호 저장, 데이터 삭제, 유료 가입·심사 신청, 승인 없이 과제 파일 쓰기. **버튼은 사람이 누릅니다.**

## 스폰지클럽 3기 과제 02 와의 관계
6회차 과제 02 「운영 OS 만들기」의 두 칸 — **무엇을 만들었나 / 그걸로 무엇이 줄었나** — 가 이 스킬의 v1 기획안과 사용 기록입니다. 모드 ① 끝에 02 초안을 채팅으로 보여 주고, 넣을지 물어봅니다.

## Codex · Cursor 에서 쓰기
이 저장소를 프로젝트 안에 복사(예: `tools/sponge-ops-os/`)하고 `AGENTS.md` 또는 `.cursorrules` 에 한 줄:
`운영 자동화·운영 OS 요청이면 tools/sponge-ops-os/SKILL.md 를 먼저 읽고 그 절차를 따른다.`
(예약 작업 형태는 Claude Desktop 전용입니다. 다른 도구에서는 시트 + Apps Script 형태로 옮깁니다.)

## 구조
`SKILL.md`(절차) + `references/`(상태 파악, 인터뷰, 운영 영역 카탈로그, 점수, 현황, 사람만 하는 단계, 가벼움 사다리, 브라우저 에이전트, 구현 레시피, 다시 부를 때, 함정, 인수인계) + `templates/`(운영 지도·기획안·사용 기록 원본) + `scripts/`(`state.sh` 상태 파악, `check.sh` 자체 점검).
