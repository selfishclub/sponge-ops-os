# 10 · 인터뷰 (모드 ①③)

## 공통 규칙

- **한 번에 한 질문.** AskUserQuestion 선택지 2~4개, 추천을 첫 번째에 "(추천)". "기타"는 자동으로 붙는다.
- 사실 확인용 닫힌 질문만 한 호출에 2개까지 묶는다 (S1, S4).
- **질문 상한:** S1~S8 의 AskUserQuestion 12회. 모드 선택 · 닉네임 · Q0(폴더) 와 열린 질문(S3 · S5-1 · S7)은 세지 않는다.
- **시간:** S0 AI 혼자 5분 이하 · S1~S5 약 15분 · S6~S8 약 10분. 넘치면 모인 데까지로 지도를 닫고 나머지는 00-map 7절 「나중에 채울 것」.
- **보여 줄 때는 쉬운 말로.** `L-A1` 같은 ID, `d`·`r`·`칸 2` 같은 기호는 문서에만 쓴다. 사용자에게는 "구글 시트 + 알림 메일", "건당 90원 (2026-09-13 기준)", "심사 3~7일"처럼 값과 기준일로.
- 답을 받을 때마다 한 줄로 되짚고 넘어간다. 용어는 풀어서 쓴다 ("API" → "공식 연결").
- 금액·사람을 물을 때는 범위·역할로 묻는다 ("월 50만 원대", "알바 2명").
- Codex·Cursor 처럼 선택지 도구가 없으면 번호 목록으로 묻는다.

## Q0 상태 파일 폴더 (필요할 때만)

00-detect §1 이 「스폰지클럽 저장소」나 「코드 없음」이면 먼저 묻는다.

> 운영 지도와 기획안을 어느 폴더에 둘까요?

선택지: 내 프로젝트 폴더 (추천 — 경로를 알려 주세요) / 지금 폴더 (「코드 없음」일 때만) / 새 폴더 `~/ops-os` 만들기

- 스폰지클럽 저장소 안(과제 폴더 속 랜딩 폴더 포함)은 선택지에 넣지 않는다.
- 고른 폴더에서 `state.sh` 를 다시 돌린다.
- git 저장소가 아니면 "커밋 없이 파일로만 남아요"라고 알려 준다.

## S1 사업·사람 (닫힌 질문 2개, 한 호출)

- Q1 "지금 운영은 누가 하나요?" — 혼자 / 나 + 가족·지인 / 직원·알바 있음 / 팀
- Q2 "사업 모양에 가장 가까운 것은?" — 온라인 신청·교육·코칭 / 매장·오프라인 서비스 / 상품 판매·납품 (B2B·공방 포함) / 아직 준비 중

→ 00-map frontmatter. 제출물·저장소로 이미 분명하면 건너뛴다.

## S2 흐름 걷기 (다중 선택)

S0 흐름 표를 보여 주고 묻는다: "이 중 **지금 손으로 하는** 것을 골라 주세요."
선택지는 운영자 손일 추정 상위 4개 (넘으면 두 질문으로). "기타"로 빠진 단계를 받는다.

→ 지도 행 (출처: 흐름 N단계). 흐름 원천이 없으면 건너뛴다.

## S3 털어놓기 (열린 질문)

> 요즘 운영하면서 **제일 하기 싫거나, 자꾸 미루거나, 실수할까 봐 겁나는 일** 세 가지만 편하게 말해 주세요. 랜딩이랑 상관없어도 돼요 — 세금계산서, 직원, 정산, 뭐든요.

- 원문을 요약하지 않고 00-map 2절에 남긴다.
- 말한 순서와 세기를 기억한다 (12-scoring H 동점 규칙 2).
- 한 문장에 일이 여럿이면 행을 나눈다 (게이트 G1).
- 실제로 돈·법 문제가 난 적이 있다는 말이 나오면 표시해 둔다 (12-scoring G 위험 우선).
- "막막하다"만 나오면 한 번만 되묻는다: "지난주에 하다가 한숨 나왔던 일 하나만요."

## S4 영역 훑기 (다중 선택 2개, 한 호출)

- 질문 A: 세금계산서·증빙 / 직원·알바 / 정산·부가세·장부 / 고객 메시지
- 질문 B: 예약·주문·재고 / 문의·리뷰 / 콘텐츠 발행 / 숫자·보고

고른 영역마다 `11-ops-catalog.md` 의 「흔한 손일」을 보여 주고 해당하는 것만 다중 선택 (영역이 3개를 넘으면 S3 에서 말한 영역부터 3개). S2·S3 에서 이미 나온 일은 다시 묻지 않는다.

## S5 숫자·준비

1. 행마다 주기·한 번(분)·v1 뒤에도 사람이 할 몫·실수 위험을 **AI 가 들은 말로 먼저 채운 표**를 보여 주고 "틀린 칸만 고쳐 주세요" (텍스트 답 1회). 들은 적 없는 칸은 "추정". 이번 모집·이벤트가 끝나면 사라지는 일인지도 같이 확인한다 (G5).
2. 상위 후보에 필요한 준비물만 다중 선택 — 사업자등록 있음 / 카카오 비즈니스 채널 있음 / 홈택스를 인증서·간편인증으로 씀 / 구글 계정·시트 씀.

→ 줄이는(분) · 준비 난이도 확정 (`12-scoring.md` A·D) → 게이트 G1~G5 → 점수 · 위험 우선.

## S6 v1 고르기 (단일 선택)

00-map 3·4절을 보여 주고, 게이트를 통과한 점수 상위와 위험 우선 행을 고르게 한다. 선택지 최대 4개: 1위 (추천) / 2위 / 3위 또는 위험 우선 / 지도만 만들고 멈춤 (→ ③).
선택지마다 한 줄, 쉬운 말로: 점수 · 왜 · 어떤 형태 · 사람이 직접 할 것 · 준비 기간 · 비용.

예시 문안 (12-scoring I 계산 예와 같은 사장님):

> ① 리뷰 답글 초안 (60점) — 매일 10분, 답이 늦다는 리뷰가 있었음 · 새 리뷰를 붙여 넣으면 답글 초안 3개 + 복사 · 올리기는 직접 · 오늘 가능 · 0원
> ② 알바 임금명세서 (20점) — 매달 1시간 · 근무 시트에서 명세서 초안 → Gmail 초안 · 보내기와 이체는 직접 · 오늘 가능 · 0원
> ③ 세금계산서 기한 알림 (위험 우선) — 작년에 기한을 넘겨 가산세 · 발행 목록 시트 + 5일·9일에 나에게 메일 · 발급은 홈택스에서 직접 · 오늘 가능 · 0원 (나중에 발급 API 는 건당 90원, 2026-09-13 기준)
