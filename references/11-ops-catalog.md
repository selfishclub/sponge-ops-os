# 11 · 운영 영역 카탈로그

인터뷰 S4(영역 훑기)에서 고른 영역의 「흔한 손일」을 보여 주고, 운영 지도 행의 「자동화 경로」와 「준비·승인」을 채울 때 쓴다. 값(단가·기한·API 상태)은 `13-latest.md` ID 로만 가리킨다. **쓰기 먼저** 는 직접 만들기 전에 이미 있는 무료 도구를 권하라는 뜻이다.

칸 번호는 `20-form-ladder.md` 사다리: 1 예약 작업 · 2 시트+Apps Script · 3 브라우저 에이전트 · 4 기존 어드민 화면 · 5 새 작은 앱.

## I. 1차 전환 흐름 안의 일

신청 확인 연락, 명단 정리, 발송 대상 추출, 신청자 메모·태그 → 칸 4 로 sponge-admin-kit 모드 ⑤ 의 EXT-01(명단) · EXT-02(발송 대상) · EXT-05(메모·태그) 형식을 따른다. 쓰기가 생기면 EXT-06 감사 로그. 어드민 자체가 없으면 sponge-admin-kit 모드 ① 을 먼저 권한다.

## 공통 설계 원칙 (조사에서 나온 것)

- 준비물과 준비 기간(사업자등록·인증서·채널 심사·프로페셔널 계정)을 먼저 묻는다.
- 첫날 v1 은 **승인 없이 되는 경로**(나에게 메일·Gmail 초안·복사 버튼·시트)로 만든다.
- **기한 리마인더가 가장 싸고 가치가 크다.** 세금계산서·부가세·급여일·4대보험.
- 만들기 전에 건당 비용을 보여 준다 (13-latest A).
