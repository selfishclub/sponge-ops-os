# 12 · 운영 지도 · 점수 · v1 게이트

## A. 운영 지도 열 정의 (`templates/00-map.md` 3절)

| 열 | 뜻 | 채우는 법 |
|---|---|---|
| # | 행 번호 | 1부터. 한 번 붙인 번호는 바꾸지 않는다 (기획안이 번호로 가리킨다) |
| 일 | 손으로 하는 일 하나 | 동사로 끝낸다. "신청자에게 안내 카톡 보내기" |
| 영역 | `11-ops-catalog.md` A~I | 하나만 |
| 누가 | 지금 누가 하나 | 나 / 가족·지인 / 직원·알바 / 외주 |
| 주기 | 얼마나 자주 | 아래 B 표의 이름 |
| 한 번(분) | 한 번 할 때 걸리는 분 | 사장님 말 그대로. 모르면 AI 추정 + "추정" |
| 주당(분) | 주기 × 한 번 | B 표로 계산 |
| 실수 위험 | 1~3 | C 표 |
| 사람만 하는 단계 | `[인증]` `[서명]` `[송금]` `[게시·발송]` `[제출·신고]` | `14-human-only.md` A. 없으면 — |
| 준비·승인 | 가장 가벼운 v1 경로에 필요한 준비와 기간 | `13-latest.md` ID 와 함께. 예: "없음", "알림톡 심사 L-C6 (v2)" |
| 준비 난이도 | 1~4 | D 표 |
| 자동화 경로 | v1 / v2 경로 한 줄씩 | `11-ops-catalog.md` 에서 |
| 점수 | E 식 | 소수점 없이 반올림 |
| 출처 | 어디서 나온 행인가 | 흐름 N단계 / 털어놓기 / 영역 훑기 / 저장소 |

15행을 넘기면 점수가 낮은 것부터 7절 「나중에 채울 것」으로 옮긴다.

## B. 주기 → 주당 횟수

| 주기 | 매일(영업일) | 주 3회 | 매주 | 격주 | 매월 | 분기 | 연 1회 |
|---|---|---|---|---|---|---|---|
| 주당 횟수 | 5 | 3 | 1 | 0.5 | 0.25 | 0.08 | 0.02 |

"월 12건을 월말에 몰아서"처럼 한 번에 여러 건이면 한 번(분) 에 건수를 곱해 넣는다. 예: 매월 · 12건 × 5분 = 60분 → 주당 15분.

## C. 실수 위험 r → 가중치 w

| r | 뜻 | w |
|---|---|---|
| 1 | 틀려도 다시 하면 된다 | 1 |
| 2 | 고객이 알아채거나 돈이 조금 걸린다 | 1.5 |
| 3 | 돈·법·신뢰 — 세금계산서 기한, 임금명세서, 4대보험 신고, 광고 표기, 개인정보, 이중 발송 | 2 |

- **기한이 있는 일(놓치면 가산세·과태료)은 r = 3.** 근거는 `13-latest.md` C 절 ID 를 적는다.
- 최근 한 달 안에 실제로 놓치거나 틀린 적이 있으면 한 단계 올린다 (최대 3).

## D. 준비 난이도 d

**완전 자동화가 아니라 "가장 가벼운 반자동 v1 경로" 기준으로 매긴다.**

| d | 뜻 | 예 |
|---|---|---|
| 1 | 오늘 바로 — 계정 있음, 승인 없음 | 구글 시트, 내 메일로 리마인더, 기존 어드민에 화면 |
| 2 | 1~3일 준비 — 키 발급, 시트 정리, 템플릿 작성 | 공공데이터 인증키, 커머스API 앱 등록 |
| 3 | 심사·계약·인증서 등록 필요 | 알림톡 채널 심사 (L-C6), 발급 API 인증서 등록 (L-A1), 유료 계약 |
| 4 | 공식 경로 없음 — 약관 금지·API 없음 | 오픈채팅 자동 발송, 네이버 블로그 자동 게시 → 초안·복사만 가능 |

## E. 점수

**점수 = 주당(분) × w ÷ d**

## F. 게이트 — 점수보다 먼저. 하나라도 걸리면 v1 후보에서 빼거나 다시 정의한다

| 게이트 | 질문 | 걸리면 |
|---|---|---|
| G1 | 한 가지 일인가 | 여러 일이 묶여 있으면 쪼개서 행을 나눈다 |
| G2 | 반자동이 되나 — 사람만 하는 단계 바로 앞에서 멈추고, 사람이 확인한 뒤 버튼 하나로 끝나나 | 판단이 매번 달라 버튼 하나로 안 되면 "준비만" 으로 다시 정의 (목록·초안까지) |
| G3 | 하루 안에 되나 (d ≤ 2) | d = 3 이면 **승인 없이 되는 앞부분**(목록 준비 + 기한 리마인더 + 초안·복사)으로 행을 다시 정의해 다시 채점. 승인이 필요한 부분은 "v2 깊게" 메모로. d = 4 면 초안·복사 버튼 행으로 바꾼다 |
| G4 | 사람만 하는 단계가 일의 대부분이 아닌가 | 인증·서명·제출이 시간의 70% 이상이면 빼고 "기한 리마인더" 행으로 바꿔 넣는다. 리마인더는 싸고 가치가 크다 |

게이트 결과는 00-map 4절에 행마다 통과/다시 정의/탈락 + 사유로 남긴다.

## G. 동점 (±10%) 일 때 순서

1. 실수 위험이 높은 쪽
2. 사장님이 털어놓기에서 먼저, 세게 말한 쪽 (써야 줄어든다)
3. 1차 전환 흐름 안의 일 (과제 02 이야기와 고객 경험에 바로 이어진다)
4. 사다리(`20-form-ladder.md`)에서 더 가벼운 칸
5. 준비 기간이 짧은 쪽

점수 차이가 10% 를 넘어도, 사장님이 2·3위를 가장 무겁게 말했으면 S6 에서 **점수는 그대로 두고** 이유를 같이 보여 줘 고를 수 있게 한다. 순서를 몰래 바꾸지 않는다.
