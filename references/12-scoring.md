# 12 · 운영 지도 · 점수 · v1 게이트

## A. 운영 지도 열 정의 (`templates/00-map.md` 3절)

| 열 | 뜻 | 채우는 법 |
|---|---|---|
| # | 행 번호 | 1부터. 한 번 붙인 번호는 바꾸지 않는다 (기획안이 번호로 가리킨다) |
| 일 | 손으로 하는 일 하나 | 동사로 끝낸다. "신청자에게 안내 카톡 보내기" |
| 영역 | `11-ops-catalog.md` A~I | 하나만 |
| 누가 | 지금 누가 하나 | 나 / 가족·지인 / 직원·알바 / 외주 |
| 주기 | 얼마나 자주 | 아래 B 표의 이름 |
| 한 번(분) | 한 번 할 때 걸리는 분 | 사장님 말 그대로. 모르면 AI 추정 + "추정" |
| 주당(분) | 주기 × 한 번 | B 표로 계산 |

| 실수 위험 | 1~3 | C 표 |

| 준비·승인 | v1 경로에 필요한 준비와 기간 | `13-latest.md` ID 와 함께. 예: "없음", "알림톡 심사 L-C6 (v2)" |

15행을 넘기면 점수가 낮은 것부터 7절 「나중에 채울 것」으로 옮긴다.

## B. 주기 → 주당 횟수

| 주기 | 매일(영업일) | 주 3회 | 매주 | 격주 | 매월 | 분기 | 반기 | 연 1회 | 2년 |
|---|---|---|---|---|---|---|---|---|---|
| 주당 횟수 | 5 | 3 | 1 | 0.5 | 0.25 | 0.08 | 0.04 | 0.02 | 0.01 |

- **건마다**(신청·주문·리뷰가 올 때마다) = 최근 4주 건수 ÷ 4.
- "월 12건을 월말에 몰아서"처럼 한 번에 여러 건이면 한 번(분) 에 건수를 곱해 넣는다. 예: 매월 · 12건 × 5분 = 60분 → 주당 15분.

## C. 실수 위험 r → 가중치 w

| r | 뜻 | w |
|---|---|---|
| 1 | 틀리거나 늦어도 아무도 모르고, 다시 하면 된다 | 1 |
| 2 | 고객이 알아챈다 — 답장·리뷰 답글이 늦음, 안내가 빠짐 — 또는 돈이 조금 걸린다 | 1.5 |
| 3 | 돈·법·신뢰 — 세금계산서 기한, 임금명세서, 4대보험 신고, 광고 표기, 개인정보, 이중 발송 | 2 |

- **기한이 있는 일(놓치면 가산세·과태료)은 r = 3.** 근거는 `13-latest.md` C 절 ID 를 적는다.
- 최근 한 달 안에 실제로 놓치거나 틀린 적이 있으면 한 단계 올린다 (최대 3).

## D. 준비 난이도 d

**v1 로 실제로 만들 경로 기준**으로 매긴다. 처음에는 그 일을 자동화하는 가장 자연스러운 경로로 매기고, G3 에서 행을 다시 정의하면 **다시 정의한 경로로 d 와 줄이는(분)을 둘 다 다시 매긴다.** 원래 행은 4절 게이트 표에 남기고, 3절 지도에는 다시 정의한 행만 둔다.

| d | 뜻 | 예 |
|---|---|---|
| 1 | 오늘 바로 — 계정 있음, 승인 없음 | 구글 시트, 나에게 리마인더 메일, Gmail 초안, 기존 어드민에 화면 |
| 2 | 1~3일 준비 — 키 발급, 시트 정리, 템플릿 작성 | 공공데이터 인증키(사업자 상태 조회 L-B1), 커머스API 앱 등록 |
| 3 | 심사·계약·인증서 등록 필요 | 알림톡 채널 심사 (L-C6), 발급 API 인증서 등록 (L-A1), 유료 계약 |
| 4 | 공식 경로 없음 — 약관 금지·API 없음 | 오픈채팅 자동 발송, 네이버 블로그 자동 게시 |

## E. 점수

**점수 = 줄이는(분) × w ÷ d**

전체 주당(분)이 아니라 **v1 이 줄이는 분**으로 매긴다. 크지만 v1 이 거의 못 줄이는 일이 위로 올라가지 않게 하기 위해서다.

## F. 게이트 — 점수보다 먼저. 걸리면 다시 정의하거나 뺀다

| 게이트 | 질문 | 걸리면 |
|---|---|---|
| G1 | 한 가지 일인가 | 여러 일이 묶여 있으면 쪼개서 행을 나눈다 |
| G2 | 반자동이 되나 — 사람만 하는 단계 바로 앞에서 멈추고, 사람이 확인한 뒤 버튼 하나로 끝나나 | 판단이 매번 달라 버튼 하나로 안 되면 "준비만"(목록·초안까지)으로 다시 정의 |
| G3 | 하루 안에 되나 (d ≤ 2) | d = 3 이면 **승인 없이 되는 앞부분**(목록 준비 · 기한 리마인더 · 초안 + 복사)으로 다시 정의하고 D 대로 다시 채점. 승인이 필요한 부분은 "v2 깊게" 메모로. d = 4 면 초안 + 복사 버튼 행으로 |
| G4 | 사람 몫이 주당(분)의 70% 미만인가 | 70% 이상이면 v1 이 줄일 게 거의 없다 → 「기한·준비 리마인더」 행으로 바꾼다 (G 절) |
| G5 | 앞으로 4주 이상 계속되는 일인가 | 이번 모집·이벤트가 끝나면 사라지는 일이면 7절 「나중에 채울 것」으로 |

게이트 결과는 00-map 4절에 행마다 통과 / 다시 정의 / 탈락 + 사유로 남긴다.

## G. 위험 우선

점수는 시간을 재서, 한 번 놓치면 큰일 나는 일을 못 잡는다. 그래서:

- **r = 3 이고 최근 1년 안에 실제로 돈·법 문제(가산세·과태료·민원)가 난 일**, 또는 **G4 로 리마인더 행이 된 r = 3 일**은 점수를 매기지 않고 「위험 우선」 표시를 붙인다.
- S6 선택지에 점수 상위와 따로 **하나** 넣는다 (선택지 4개 한도 안에서 3위 자리를 쓴다).
- 리마인더 행은 대개 d = 1 · 0원이라 v1 로 하루에 끝난다.
- 문제 이력이 없는 G4 리마인더 행은 7절로 보내고, 사장님이 원하면 올린다.

## H. 동점 (±10%) 일 때 순서

1. 실수 위험이 높은 쪽
2. 사장님이 털어놓기에서 먼저, 세게 말한 쪽 (써야 줄어든다)
3. 1차 전환 흐름 안의 일 (과제 02 이야기와 고객 경험에 바로 이어진다)
4. 사다리(`20-form-ladder.md`)에서 더 가벼운 칸
5. 준비 기간이 짧은 쪽

점수 차이가 10% 를 넘어도, 사장님이 아래 순위를 가장 무겁게 말했으면 S6 에서 **점수는 그대로 두고** 그 말을 같이 보여 줘 고를 수 있게 한다. 순서를 몰래 바꾸지 않는다.
