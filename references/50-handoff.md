## c. 과제 02 초안 (스폰지클럽 크루일 때) — 채팅에만 보여 준다

```markdown
**무엇을 만들었나:** {{일}} — {{형태}}. {{준비 단계}}는 {{AI·스크립트}}가 하고, 저는 {{버튼}}만 누릅니다.

**그걸로 무엇이 줄었나:** 주 {{X}}분 → 주 {{Y}}분 ({{N}}회 실측) · 실수 {{a}} → {{b}}

**📸 화면 캡처:** ① 버튼 직전 화면 ② 결과 화면 ③ log.md
```

log 가 없거나 3줄 미만이면 두 번째 줄을 이렇게 쓴다: "예상 주 {{X}}분 → 주 {{Y}}분 · 마감 전에 {{N}}번 써 보고 실측으로 바꿉니다".

## d. submission.md 에 넣을 때

AskUserQuestion: 넣기 / 채팅으로만 / 나중에.
**"넣기"일 때만** 스폰지클럽 저장소에서:

1. `git pull`
2. 본인 폴더의 `1_mission/{조}/{닉네임}/5. 6회차 과제 · 7회차 9월 20일까지 제출/submission.md` 에서 `## 02.` 와 `## 03.` 사이만 고친다. 다른 절과 다른 크루 폴더는 건드리지 않는다.
3. 캡처는 사용자가 준 파일만 같은 폴더에 둔다.
4. 커밋 `{{조}} {{닉네임}} 6회차 02 운영 OS — {{일}} v1` → push. 실패하면 force 하지 않고 알린다.

## e. 프로젝트 저장소 커밋

| 시점 | 커밋 메시지 |
|---|---|
| S8 뒤 | `ops-os: 운영 지도 + v1 기획안 — {{일}}` |
| 구현 기능 하나마다 | `ops-os v1: {{기능}}` |
| 운영 시작 | `ops-os v1: 운영 시작 — log 시작` |
| 모드 ② | `ops-os: v1 회고 → v2 {{깊게·넓게}} 기획안` |

- **저장소가 공개**(`gh repo view --json visibility`)면 `docs/ops-os/` 커밋 전에 묻는다. 이름·금액·고객 정보가 역할·범위로만 적혔는지 같이 확인하고, 원하면 `.gitignore` 에 넣거나 비공개 저장소로 옮긴다.
- `docs/ops-os/out/` 과 로그인 파일은 `.gitignore`.
- 커밋 전 `git diff --cached` 로 env 파일·키가 없는지 본다.
- 원격이 있으면 커밋 직후 push. 실패하면 force 하지 않고 알린다.
- 폴더가 git 저장소가 아니면 커밋을 건너뛰고 "기록은 파일로만 남았다"고 알린다. git 을 쓸지는 사용자가 정한다 (새로 시작하면 `20-form-ladder.md` D 순서).
